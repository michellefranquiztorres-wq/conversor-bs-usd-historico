# Conversor Bs/USD con histórico

Aplicación web para consultar, convertir y visualizar la evolución histórica del tipo de cambio entre el bolívar venezolano (Bs) y el dólar estadounidense (USD).

## Objetivo

Facilitar la consulta de valores históricos del tipo de cambio, permitiendo visualizar su evolución mediante gráficos y buscar valores correspondientes a fechas específicas.

## Funcionalidades previstas

- Conversión Bs/USD.
- Consulta de registros históricos.
- Visualización de la evolución del tipo de cambio mediante gráficos.
- Búsqueda de valores por fecha.
- Consulta eficiente de datos históricos.

## Tecnologías

- TypeScript
- Node.js
- PostgreSQL
- JavaScript
- HTML y CSS
